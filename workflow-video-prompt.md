# NOMA Example Workflow Video Prompt

Use this prompt in an AI video generator (Runway Gen-3, Sora, Pika, Kling, etc.).

## Master Prompt

Create a sleek 45-second product workflow video for a startup called **NOMA**.

Style: premium Apple-like liquid glass UI, translucent panels, modern gradients, subtle reflections/refractions, minimal typography, smooth camera motion, polished startup ad aesthetic.

Narrative:
1. A traveler sends a message to a travel advisor asking for an Everest Base Camp hike.
2. The advisor opens NOMA and browses global local-operator trip options.
3. NOMA AI agents compare pricing, trip duration, route details, and amenities.
4. Back-and-forth coordination happens seamlessly between advisor and operators.
5. NOMA outputs a fully bookable itinerary with clear pricing and logistics.
6. End with: "NOMA — AI agents empowering modern travel advisors."

Visual requirements:
- Show world map/global routing motifs
- Show Everest region references and mountain visuals
- Show UI cards for price, duration, amenities, availability
- Show communication bubbles between traveler, advisor, and operators
- Use calm but energetic motion, no chaotic cuts
- Keep text concise and readable

Mood: trustworthy, global, adventurous, operationally powerful.
Color palette: glass whites, soft blues, indigo, cyan accents.
Aspect ratio: 16:9.
Resolution: 1920x1080.

## Shot-by-Shot Script (45s)

### Shot 1 (0-6s): Traveler Intent
- Close-up of chat message: "Looking for an Everest Base Camp trek for 2 people in October."
- UI appears as frosted glass overlay.
- Title: "Traveler request received."

### Shot 2 (6-13s): Advisor Workspace
- Advisor dashboard opens in NOMA.
- Cards slide in: Nepal, Everest Base Camp, 12 days, moderate difficulty.
- Tag: "Advisor workspace".

### Shot 3 (13-22s): Global Operator Discovery
- Animated world map with arcs from advisor to local operators in Nepal and nearby regions.
- Operator cards show: price range, availability, amenities, response time.
- Tag: "Global local supply, unified".

### Shot 4 (22-31s): AI Coordination
- AI agent panel auto-compares options.
- Side-by-side matrix updates: Duration, Price, Permits, Guide quality, Lodging.
- Chat snippets update in real time between advisor and operators.
- Tag: "AI handles logistics and communication".

### Shot 5 (31-39s): Bookable Itinerary
- Final itinerary card assembles with timeline:
  - Day-by-day route
  - Total price
  - Included amenities
  - Confirmed availability
- CTA-like button appears: "Ready to Book".

### Shot 6 (39-45s): Brand End Card
- Gentle pullback over liquid-glass globe and mountain silhouette.
- Text:
  - "NOMA"
  - "AI agents empowering modern travel advisors"
  - "Plan. Price. Book. Seamlessly."
